# Броня и коррозия (без учёта игнорирования брони)

Как считается снижение урона от брони и может ли моб вообще не получать урон. Как работает коррозия (снятие брони) и что значит число «60K» в интерфейсе.

Источники: `modifiers/eom_modifier/properties.lua` (GetArmor, GetArmorDamageReduction, GetArmorReduction), `mechanics/damage_system.lua`, `modifiers/modifier_reduce_armor.lua`, `abilities/server.lua` (ReduceArmor), `constant.lua` (ARMOR_FACTOR).

---

## 1. Как считается броня цели

**GetArmor(unit)** — итоговая броня юнита:

- База: `GetBaseArmor` (OriginalValue "Armor", ARMOR_LEVEL, модификаторы ARMOR, TEAMHERO_ARMOR, ARMOR_PERCENTAGE).
- Дополнительно: `GetArmorAmplification` (усиление брони в %).
- Формула: **Armor = BaseArmor × (1 + ArmorAmplification/100)**.

Броня может быть отрицательной (например после коррозии): тогда урон от брони не снижается, а **увеличивается** (см. формулу ниже).

---

## 2. Снижение урона от брони (без игнора брони)

В коде **игнорирование брони не учитывается** (по твоему запросу). Тогда используется только формула снижения от «эффективной» брони.

**GetArmorDamageReduction(victim, t)** возвращает долю урона, **которую броня снимает** (число от 0 до 1):

```
ARMOR_FACTOR = 0.01   (constant.lua)

fValue = GetArmor(victim, t)   // может быть отрицательной после коррозии

снижение = ARMOR_FACTOR × fValue / (1 + ARMOR_FACTOR × |fValue|)
```

То есть:

**снижение = 0.01 × броня / (1 + 0.01 × |броня|)**

- При **броне = 0**: снижение = 0 → весь урон проходит.
- При **броне > 0**: снижение от 0 до 1 (не достигая 1 при конечной броне).
- При **броне < 0**: снижение отрицательное → урон **усиливается**.

Доля урона, которая **доходит** до цели:

**оставшийся_урон = 1 - снижение**

В `damage_system.lua`:

```lua
remaining = 1 - GetArmorDamageReduction(t.victim, t)
t.physical_damage = t.physical_damage * remaining
t.magical_damage = t.magical_damage * remaining
```

(Маг урон в этой игре тоже режется тем же фактором, если не стоит игнор маг. брони.)

---

## 3. Получит ли моб урон, пока на нём броня?

**Да. При любой конечной броне моб всегда получает часть урона.**

Формула снижения: **снижение = 0.01×armor / (1 + 0.01×|armor|)**. При любом конечном положительном armor знаменатель больше числителя, поэтому **снижение всегда строго меньше 1**. Значит **оставшийся_урон = 1 - снижение всегда больше 0**.

Примеры:

| Броня | Снижение      | Оставшийся урон |
|-------|---------------|------------------|
| 0     | 0%            | 100%             |
| 50    | 33.(3)%       | ~66.7%           |
| 100   | 50%           | 50%              |
| 200   | 66.(6)%       | ~33.3%           |
| 1000  | ~90.9%        | ~9.1%            |
| 10000 | ~99%          | ~1%              |

Даже при очень большой броне до цели доходит хотя бы малая доля урона. Нулевой урон был бы только при **бесконечной** броне, чего в игре нет.

---

## 4. Коррозия (снятие брони) — как работает

«Коррозия» в интерфейсе — это параметр **GetArmorReduction(атакующий)**: число (например 60 000), которое показывается как стат героя. Оно **не** «урон от коррозии», а **насколько снимается броня с цели за один удар** (при коэффициенте 1).

### 4.1. Откуда берётся число (60K и т.п.)

**GetArmorReduction(unit, t)** считается из модификаторов:

- **ARMOR_REDUCTION** — плоское значение (база «коррозии»).
- **ARMOR_REDUCTION_PERCENTAGE** и **ARMOR_REDUCTION_PERCENTAGE_MULTIPLE** — проценты и множители (в т.ч. от цели и невидимости).

Формула в коде:

```lua
value   = GetModifierProperty(unit, EOM_MODIFIER_PROPERTY_ARMOR_REDUCTION, t)
increase = ...  -- проценты
more    = ...   -- множители
return value * (1 + increase/100) * (1 + more/100)
```

То, что ты видишь в игре (60K), — это и есть **GetArmorReduction(герой)**: суммарное значение после всех бонусов.

### 4.2. Что происходит при ударе по цели

При применении физ/маг урона по цели (в `damage_system.lua`):

1. Собирается **armor_reduction_factor** у атакующего (обычно 1 для обычной атаки; может быть больше от способностей/предметов).
2. Считается: **value = armor_reduction_factor × GetArmorReduction(атакующий, t)**.
3. У цели накапливается: **victim.__ReduceArmor = (victim.__ReduceArmor или 0) + value**.
4. На цель вешается модификатор **modifier_reduce_armor** с параметром **duration = victim.__ReduceArmor**.

В **modifier_reduce_armor** задано:

```lua
EOM_MODIFIER_PROPERTY_ARMOR = function() return -self:GetDuration() end
```

То есть модификатор **уменьшает броню цели на число, равное своей длительности**. Длительность модификатора при этом равна текущей сумме **__ReduceArmor**. При каждом новом ударе эта сумма увеличивается на **value**, модификатор перезаписывается с новой длительностью, и броня цели считается как **базовая броня минус эта сумма**.

Итого:

- **За один удар** с фактором 1 с цели «снимается» **GetArmorReduction(атакующего)** единиц брони в смысле: к **__ReduceArmor** прибавляется это число, и эффективная броня цели = база − **__ReduceArmor**.
- Число **60K** в статах значит: при каждом таком ударе к снятию брони добавляется **60 000**. Если у моба было 100 брони, после первого удара у него 100 − 60 000 = **−59 900** брони — урон от брони уже не снижается, а **увеличивается** (отрицательная броня даёт отрицательное «снижение» в формуле выше).

### 4.3. Сводка по коррозии

| Что | Значение |
|-----|----------|
| **Коррозия 60K в UI** | **GetArmorReduction(герой)** = на сколько единиц увеличивается снятие брони с цели за один удар (при factor = 1). |
| **За удар** | К **__ReduceArmor** цели прибавляется **armor_reduction_factor × GetArmorReduction(атакующий)**. |
| **Эффект на броню** | У цели висит модификатор, который даёт **ARMOR = −(__ReduceArmor)**. Эффективная броня = базовая броня + (этот модификатор) = базовая − **__ReduceArmor**. |
| **Несколько ударов** | Каждый удар добавляет к **__ReduceArmor** новую порцию. Броня цели падает (и может уйти в минус), урон по цели растёт. |

Игнорирование брони в этом документе не рассматривается; оно может дополнительно менять расчёт в коде, но на описанную логику брони и коррозии не влияет.

# То же самое с учётом игнорирования брони

Ниже — те же разделы (броня цели, снижение урона, «получит ли моб урон», коррозия), но с учётом **игнорирования брони** атакующим и целью.

---

## 5. Как считается броня цели (без изменений)

Итоговая броня цели считается так же: **GetArmor(victim, t)** = BaseArmor × (1 + ArmorAmplification/100). Сюда уже входит коррозия (модификатор **modifier_reduce_armor** даёт ARMOR = −__ReduceArmor). Игнор брони **не** меняет саму броню цели — он меняет только то, **какая доля этой брони** подставляется в формулу снижения урона (см. ниже).

---

## 6. Снижение урона от брони с учётом игнора

**GetArmorDamageReduction(victim, t)** в коде делает следующее.

1. **Берётся броня цели:** **fValue = GetArmor(victim, t)** (уже с учётом коррозии и прочих модификаторов).

2. **Если fValue > 0**, считается **эффективная броня** для формулы:
   - **Плоское игнорирование:** у цели — IGNORE_ARMOR_TARGET, у атакующего — **GetIgnoreArmor(attacker, t)** (подставляется вместо цели, если есть attacker). Из брони вычитается: **fValue = max(fValue − ignore, 0)**.
   - **Процентное игнорирование:** у цели — IGNORE_ARMOR_PERCENTAGE_TARGET, у атакующего — **GetIgnoreArmorPercentage(attacker, t)**. Проценты объединяются через **CompoundDecreaseSimple** (игнор сильнее). Броня умножается на **(1 − ignorePercent/100)**: **fValue = max(fValue × (1 − ignorePercent/100), 0)**.

3. Опционально **RealArmor**: если у юнита задан RealArmor и базовая броня больше него, fValue ремапится в диапазон [0, baseRealArmor].

4. **Формула снижения** (та же, что и без игнора):

**снижение = ARMOR_FACTOR × fValue / (1 + ARMOR_FACTOR × |fValue|)**

В расчёт идёт уже **эффективная броня** fValue (после вычитания плоского игнора и умножения на (1 − процент_игнора)).

Итого с учётом игнора:

- **Эффективная_броня** = max(0, (броня_цели − плоский_игнор) × (1 − процент_игнора/100)).
- **снижение** = 0.01 × эффективная_броня / (1 + 0.01 × |эффективная_броня|).
- **оставшийся_урон** = 1 − снижение.

Коррозия по-прежнему уменьшает **броню цели** (GetArmor меньше), а игнор потом дополнительно уменьшает **эффективную броню** в этой формуле. Оба эффекта складываются: сначала меньше броня от коррозии, потом эта броня ещё режется игнором.

---

## 7. Получит ли моб урон при учёте игнора?

**Да. При любой конечной эффективной броне моб всегда получает часть урона.**

- Если **эффективная броня = 0** (полный игнор или сняли коррозией): снижение = 0, **оставшийся_урон = 100%** — моб получает весь урон без снижения от брони.
- Если эффективная броня положительная и конечная: снижение строго меньше 1, значит часть урона всё равно доходит (как в таблице выше, но с подставленной эффективной бронёй).
- Нулевой урон только при бесконечной эффективной броне (в игре не бывает).

Пример: у цели 100 брони, у атакующего 50% игнора брони. Эффективная броня = 100 × (1 − 50/100) = **50**. Снижение как при 50 броне (~33%), в цель идёт ~66.7% урона.

---

## 8. Коррозия с учётом игнора

Логика коррозии **не меняется**:

- **GetArmorReduction(атакующий)** — по-прежнему «на сколько единиц за удар увеличивается снятие брони с цели» (при factor = 1). Число в UI (60K и т.п.) — то же самое.
- При ударе по-прежнему: **value = armor_reduction_factor × GetArmorReduction(атакующий)** прибавляется к **victim.__ReduceArmor**, модификатор **modifier_reduce_armor** даёт **ARMOR = −__ReduceArmor**, т.е. броня цели = база − __ReduceArmor.

**Отличие только в расчёте урона:** теперь в **GetArmorDamageReduction** берётся уже эта (возможно сниженная коррозией) броня цели, затем к ней применяется **игнор** атакующего (плоский и процентный), получается эффективная броня, и по ней считается снижение. То есть коррозия и игнор работают вместе: коррозия уменьшает броню цели, игнор ещё уменьшает ту броню, которая подставляется в формулу.

Сводка с учётом игнора:

| Что | Как |
|-----|-----|
| **Броня цели** | GetArmor(victim) — уже с коррозией (минус __ReduceArmor). |
| **Эффективная броня** | max(0, (броня_цели − flat_ignore) × (1 − pct_ignore/100)). |
| **Снижение урона** | 0.01 × эффективная_броня / (1 + 0.01 × |эффективная_броня|). |
| **Оставшийся урон** | 1 − снижение (при 0 эффективной броне = 100%). |
| **Коррозия 60K** | Как и раньше: +60K к __ReduceArmor за удар (при factor=1), броня цели падает; затем к этой броне применяется игнор атакующего. |
